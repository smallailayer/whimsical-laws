# Jack's Third Law and Whimsical Laws

*A collection of whimsical laws and unconventional lenses for examining the world.*

**First law:** [j3l/001 — The Cynical Investigator (v0.1)](j3l/001-v0.1.md)

## The idea

Never assume the stated reason for an action is the real reason when someone stands to benefit from a different explanation.

Jack's Third Law is not a claim that conspiracies are everywhere. It is permission to ask awkward questions, try deliberately extreme readings and see which explanations survive scrutiny.

Invoke it in a chat by writing `j3l/` followed by an article, event, announcement or question. Its seven-part response covers conventional accounts, cynical hypotheses, interests, evidence, inconvenient questions, innocent explanations and Jack's verdict.

## Status and limits

- This is a conversational **lens**, not independent enforcement.
- It can be playful and speculative, but allegations are not facts without evidence.
- It is **not** a SAiL/SAiLA artefact.
- Preserve published versions as historical references; make subsequent substantive revisions in newly versioned files.
- This repository is independent of `a/001`, `h/` and BANDY; those artefacts remain untouched.
